## Summary

- **Definition:** A tangible, inanimate physical object (e.g., hardware, vehicle, physical document, natural object). Physical only. Use Statements (madeBy, manufactured=true) if man-made vs natural matters.
- **Not:** Not a location (where). Not a digital artifact (use CreativeWork).
- **Layer:** [Spacetime](/docs/fcp/vocabulary#spacetime)
- **Hex Code:** `43`
- **Standard Alignment:** `schema:Product` + `schema:Thing` (Close fit)
