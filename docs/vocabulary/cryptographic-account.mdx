## Summary

- **Definition:** A math-based account principal (e.g., an EVM address, Bitcoin wallet, or did:key). The identity exists mathematically and is authenticated via mathematical signature keys.
- **Not:** Authenticated via mathematical signature keys, independent of a host authority.
- **Layer:** [Network Anchors](/docs/fcp/vocabulary#network-anchors)
- **Hex Code:** `22`
- **Standard Alignment:** `sec:PublicKey` + `sec:publicKeyMultibase` (Close fit)
