## Summary

- **Definition:** A running process that acts as an independent actor: bot, AI agent, smart contract. Can hold keys and sign.
- **Not:** Not a person or organization. Not static passive code (use CreativeWork for repos, images, logic).
- **Layer:** [Agents](/docs/fcp/vocabulary#agents)
- **Hex Code:** `12`
- **Standard Alignment:** `schema:SoftwareApplication` + `prov:SoftwareAgent` (Close fit)
