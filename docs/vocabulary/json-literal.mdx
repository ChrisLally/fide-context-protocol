## Summary

- **Definition:** A structured JSON object represented in canonical string form (RFC 8785).
- **Not:** Not a string.
- **Layer:** [Literals](/docs/fcp/vocabulary#literals)
- **Hex Code:** `a9`
- **Standard Alignment:** `rdf:Literal` + `rdf:JSON` (Exact fit)
