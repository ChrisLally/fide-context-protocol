- **Definition:** A formalized Uniform Resource Identifier string (RFC 3986).

- **Layer:** [Literals](/docs/fcp/vocabulary#literals)

- **Standard Alignment:** `rdf:Literal` + `xsd:anyURI` (Exact fit)
